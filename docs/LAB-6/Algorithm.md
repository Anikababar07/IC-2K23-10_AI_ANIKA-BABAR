# Algorithm: Tensor Manipulation

1. Start the program.
2. Import the PyTorch library.
3. Create two tensors containing numerical values.
4. Perform element-wise addition of the two tensors.
5. Perform element-wise multiplication of the two tensors.
6. Create a tensor containing values from 1 to 6.
7. Reshape the tensor into a 2 × 3 matrix.
8. Display the original tensors and the results of the operations.
9. Display the shape and data type of the reshaped tensor.
10. Stop the program.
