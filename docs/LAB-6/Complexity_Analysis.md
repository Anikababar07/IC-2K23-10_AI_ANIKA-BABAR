# Complexity Analysis: Tensor Manipulation

## Time Complexity

The addition and multiplication operations process each element of the tensors.

- Tensor Addition: O(n)
- Tensor Multiplication: O(n)
- Tensor Reshaping: O(1) in typical cases

Therefore, the overall time complexity is:

**O(n)**

where n is the number of elements in the tensor.

## Space Complexity

The program creates additional tensors to store the results of the tensor operations.

Therefore, the space complexity is:

**O(n)**
