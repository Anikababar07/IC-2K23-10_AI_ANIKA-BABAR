# Pseudocode: Tensor Manipulation

BEGIN

    IMPORT PyTorch library

    CREATE tensor1 with values [1, 2, 3, 4]
    CREATE tensor2 with values [5, 6, 7, 8]

    ADD tensor1 and tensor2
    STORE result in addition

    MULTIPLY tensor1 and tensor2
    STORE result in multiplication

    CREATE tensor3 with values from 1 to 6

    RESHAPE tensor3 into a 2 × 3 matrix

    DISPLAY tensor1 and tensor2
    DISPLAY addition
    DISPLAY multiplication
    DISPLAY original tensor
    DISPLAY reshaped tensor
    DISPLAY tensor shape and data type

END
